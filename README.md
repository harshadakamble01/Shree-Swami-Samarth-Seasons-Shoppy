# Shree Swami Samarth Seasons Shoppy

A responsive black-and-gold saree catalogue website with:
- Saree category filters
- Search by style, fabric, colour and design
- Responsive product gallery
- Pack-neck / high-neck blouse styling note
- GitHub Pages-ready static files

## Important before publishing
1. Replace the WhatsApp link `https://wa.me/` in `index.html` with the shop's full WhatsApp link, including country code and number (digits only).
2. Replace the sample catalogue images and product details with the shop's actual saree photos and information.
3. The current collection contains sample styles, not a live inventory or unlimited automatic product feed. Add more product objects to the `products` array in `script.js` to expand the catalogue.

## Publish on GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `shree-swami-samarth-seasons-shoppy`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's main/root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for GitHub Pages to publish. The link will look like:
   `https://YOUR-USERNAME.github.io/shree-swami-samarth-seasons-shoppy/`

The GitHub Pages URL above is a format example; it is not a live published link.
