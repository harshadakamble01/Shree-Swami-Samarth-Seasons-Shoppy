# Shree Swami Samarth Seasons Shoppy

Responsive black-and-gold saree catalogue with:
- Search by saree type, fabric, colour and design
- Category filters for 12 different saree styles
- White-background product cards
- Mobile-friendly layout

## Before using this as the shop's official advertisement
The current catalogue photos are external reference images from third-party retail/catalogue pages, not confirmed photos of your shop's stock. Please replace them with photos you own or have permission to use. The photos may not all show pack-neck blouses; "PACK-NECK BLOUSE REQUEST" means customers can ask the shop about that styling, not that every pictured product already includes it.

To replace photos, edit the `image` field for each item in `script.js` and use your own image file paths, for example `images/jacket-saree-01.jpg`. Put those image files inside the `images` folder in this repository.

## WhatsApp
Replace `https://wa.me/` in `index.html` with the shop's WhatsApp link before publishing.

## Publish updates on GitHub
Upload/replace `index.html`, `style.css`, and `script.js` in the repository root, then commit the changes. GitHub Pages will rebuild automatically.
